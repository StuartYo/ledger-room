# Ledger Room

On-premises receipt and invoice audit station for Taiwanese bookkeeping firms (記帳業者).
Work in progress for the ASUS UGen AI League (Thunderstorm track, Workplace AI).

> **All data in this repository is SYNTHETIC.** Every company, Unified Business Number
> (統一編號), invoice number, amount and document image is generated by code
> (`synth/generate.py`, drawn with Pillow). No real people, no real business records,
> no AI-generated images. Any match with a real business is coincidental.

Status: day one. The frozen evaluation sets (`eval/expected_main.json`,
`eval/expected_heldout.json`) were committed before any model or prompt tuning.
